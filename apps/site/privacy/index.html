LeetTrace

Privacy policy

LeetTrace collects no data.

Effective October 2026 · applies to the LeetTrace app, browser extension and this website.

What LeetTrace does

LeetTrace shows how your own code runs: a desktop app (the "engine") traces your Python on your computer, and a browser extension shows the trace on LeetCode problem pages.

Your code and data stay on your computer

  • The engine runs only on your computer and listens only on the loopback address 127.0.0.1. It is not reachable from your network or the internet.
  • The extension sends your code and the problem's example inputs only to that local engine, and only when you click Trace. Every request carries a secret token, and the engine accepts browser requests only from leetcode.com and its own page.
  • The token is stored in the extension's private storage (and in ~/.leettrace on your computer). It never leaves your machine.
  • Nothing is uploaded, sold, shared, or used for advertising. There are no accounts.

What the extension reads

On leetcode.com/problems/* pages, the extension reads the problem's title, example test cases and the code in the editor — only to trace it locally when you ask. It does not read other sites, your browsing history, cookies, or your LeetCode account.

This website

This site is static. It has no analytics, no cookies, and no tracking. To show the latest download, your browser asks GitHub's public API for the latest release (api.github.com); GitHub's privacy statement applies to that request. Downloads come from GitHub Releases.

Permissions, explained

  • leetcode.com — add the Trace button and panel to problem pages.
  • 127.0.0.1 — talk to the LeetTrace app on your own computer.
  • storage — remember the connection to the app.
  • scripting — read the code from LeetCode's editor when you click Trace.

Not affiliated with LeetCode

LeetTrace is an independent open-source tool and is not affiliated with or endorsed by LeetCode.
