Welcome to LeetTrace

See your Python solution execute on the problem page: call stack, heap, pointer arrows, and a reason for every step — run on your own machine.

  1. Install the engine (one command)

    pipx install leettrace

    No pipx? python3 -m pip install --user leettrace, or download the standalone binary from the releases page.

  2. Start it

    leettrace start

    It listens on 127.0.0.1 only and runs your code in a sandboxed subprocess.

  3. Open a problem and click Trace

    The button sits next to LeetCode's Run. The first time, the panel asks for a 6-digit code — it's printed in the terminal running leettrace start. Chrome may also ask to let leetcode.com reach apps on this device: choose Allow.
