LeetTrace - before you start

FIRST TIME ONLY
If Windows showed "Windows protected your PC" before this window, that is
normal for a new open-source app that isn't code-signed yet: you clicked
More info, then Run anyway. You won't see it again for LeetTrace.

WHAT GETS INSTALLED
- LeetTrace, in Program Files, with a Start menu entry.
- It runs in the background (icon in the system tray, near the clock) and
  starts when you sign in. Turn that off any time from the tray icon.
- Your code runs only on this computer. The browser talks to LeetTrace over
  127.0.0.1 (this machine only), locked to a secret token and to leetcode.com.

AFTER INSTALLING
1. The welcome page opens in your browser: add the LeetTrace extension.
2. Open any LeetCode problem and click Trace. It connects automatically,
   with no code to type.

Uninstall any time from Settings > Apps.
LeetTrace is an independent tool, not affiliated with LeetCode.
